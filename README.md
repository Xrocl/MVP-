# MVP системы автоматизации расчета маршрутов

Данный проект представляет собой демонстрационный MVP системы поддержки принятия решений для логистической компании ООО «Тетра Транс».

MVP показывает, как может работать инструмент автоматизированного расчета маршрутной экономики и выбора наиболее эффективного сценария использования контейнерного парка. Основная задача решения – снизить зависимость от ручных расчетов, ускорить сравнение маршрутов и повысить обоснованность управленческих решений.

## Что демонстрирует MVP

- расчет экономики маршрута;
- сравнение альтернативных сценариев использования контейнера;
- учет ставки, расходов, простоев и длительности цикла;
- оценку годовой рентабельности;
- выбор наиболее эффективного варианта;
- визуальное отображение результата для логиста.

## Назначение проекта

Проект разработан в рамках выпускной квалификационной работы на тему:

«Разработка подхода к снижению себестоимости грузоперевозок компании ООО “Тетра Транс”».

MVP используется как демонстрационный прототип, показывающий возможную логику автоматизации процесса пересчета маршрутов и поддержки принятия решений.

## Как открыть проект

Проект можно открыть через GitHub Pages после публикации репозитория.

Если запускать локально, достаточно открыть файл:

`index.html`

в браузере.

## Статус проекта

Проект является учебным MVP и демонстрирует концепцию работы системы. Он не является промышленной версией продукта.
